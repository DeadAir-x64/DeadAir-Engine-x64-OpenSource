# Dead Air x64 — порт на OpenXRay

Перенос мода **Dead Air** (форк Call of Chernobyl для S.T.A.L.K.E.R.: Call of Pripyat) с 32-битного
движка на **OpenXRay** — 64-битный движок с рендером DirectX 11.

Публикуется с разрешения автора оригинального мода.

## Что в этой папке

| | |
|---|---|
| **[docs/](docs/README.md)** | документация порта: архитектура, все правки, карта Lua, производительность, консольные команды |
| **[JOURNAL_GLM.md](JOURNAL_GLM.md)**, **[PORT_REPORT_x64.md](PORT_REPORT_x64.md)** | рабочие журналы: как шёл разбор оригинала и сам перенос |
| **gamedata/shaders/r3/** | шейдеры DX11, правленные под порт — векторы движения, вода, растительность, постобработка |
| **gamedata/scripts/** | скрипты, форкнутые россыпью там, где падение приходило из Lua и чинить его из движка было нельзя |
| **gamedata/configs/** | конфиги порта: меню настроек, строки интерфейса, профили качества |

Движок — в дереве выше (`src/`). Всё, что отличает порт от чистого OpenXRay, помечено маркером
`[DA_PORT]` прямо в исходниках; полный список собирается из этих меток одной командой:

```bash
python da_port/docs/_regen_changes.py
```

## Сторонние SDK

В репозиторий не входят — у каждого своя лицензия и свой размер. Ставятся рядом:

```bash
git clone --depth 1 https://github.com/NVIDIA/DLSS.git Externals/nvngx
git clone --depth 1 https://github.com/intel/xess.git Externals/xess
```

Прослойка `Externals/nvngx_shim` — наша, она в репозитории. Нужна потому, что NVIDIA отдаёт NGX
статическими библиотеками MSVC, а порт собирается MinGW: напрямую они не линкуются (77–123
неразрешённых символа MSVC-STL и vcruntime). Подробности — в `docs/09_UPSCALERS.md`.

Условия распространения DLSS — в [NVIDIA_DLSS_LICENSE.txt](NVIDIA_DLSS_LICENSE.txt).
